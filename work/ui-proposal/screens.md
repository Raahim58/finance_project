# RAAHIM UI concepts

25 individual sample screens. This collection contains the selected revisions; it excludes the superseded dashboard drafts.

Generated with the built-in image tool. Prompt direction: adapt the inspected Rallies reference using compact sans-serif typography, flat white columns, quiet dividers, contextual evidence/Ask, PSX company context, portfolio-specific IPS, and explicit unavailable-data states. Pages retain distinct analytical workflows.

These are visual concepts, not deployed UI or authoritative financial reports. Chart geometry, company marks, and some generated labels are illustrative.
