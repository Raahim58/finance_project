# Domain docs

This repository uses a single-context domain documentation layout.

Before exploring a domain area:

1. Read `CONTEXT.md` when it exists.
2. Read relevant ADRs under `docs/adr/`.
3. If these files do not exist, proceed silently.
4. Use terminology defined in `CONTEXT.md`.
5. Surface any conflict with an existing ADR explicitly.

Expected layout:

```text
/
├── CONTEXT.md
└── docs/
    └── adr/
```
