# Architecture

`psx-ai-portfolio-agent` is a monorepo with a Next.js frontend and FastAPI backend.

## Current Phases

Phase 0 creates the repository shape, local services, docs, and skeleton apps.

Phase 1 implements:

- Email/password authentication
- Backend-issued JWT access tokens
- User preferences
- Encrypted bring-your-own LLM API key storage
- Provider-agnostic LLM interface
- Mock provider for tests

Phase 2 implements:

- PSX exchange/company tables
- Mock market price ingestion
- Market snapshots and sector daily stats
- Read-only market APIs
- Frontend market dashboard
- Frontend company detail/history page with a lightweight chart

Phase 3 implements:

- User-owned portfolios
- Holdings and transaction records
- Portfolio summary, exposure, performance, and risk-flag APIs
- Valuation and PnL calculated from stored holdings and latest market prices
- Frontend portfolio dashboard

## System Shape

```text
apps/web  ->  apps/api  ->  database
                 |
                 -> LLM provider registry
                 -> encrypted user provider keys
                 -> market data services
                 -> portfolio services
```

Structured numerical market data now lives in database tables. RAG will be used only for unstructured company, policy, and report documents in later phases.

## Phase Boundaries

RAG, policy intelligence, chat, daily digest, alerts, watchlists, and order intents are intentionally deferred. Phase 2 market data is deterministic mock data unless another source is explicitly added later.

## Market Data Flow

```text
python -m app.jobs.ingest_psx_mock
        -> companies, market_prices
        -> market_snapshots, sector_daily_stats
        -> /market APIs
        -> /market and /companies/[symbol]
```

The mock ingestion job is idempotent for rows with `source = "mock"` and preserves the rule that exact prices/rankings are read from the database, not generated by the frontend or LLM.

## Portfolio Data Flow

```text
user auth
  -> /portfolios APIs
  -> portfolio_holdings + portfolio_transactions
  -> latest market_prices
  -> summary, exposure, performance, risk flags
  -> /portfolio
```

Portfolio calculations are server-side and user-scoped. The current Phase 3 portfolio dashboard is a manual-entry MVP; broker integration, order intents, watchlists, alerts, and chat-based interpretation are later phases.
