Problem
The interface is the test surface, but current tests must enter a call-order-heavy implementation where security fit skips normal planning and ordinary fit questions can skip company evidence search.
Solution
Concentrate reasoning policy in one deep module; keep provider behavior behind adapters and deterministic truth behind the context seam.
Deletion test
Deleting planner or validator helpers merely expands the orchestration function; the policy needs greater locality.
  • locality: policy in one module
  • leverage: every intent
  • two adapters justify seam
  • fallback tests survive
