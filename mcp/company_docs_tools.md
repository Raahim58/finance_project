# Company Docs Tools

Planned read-only tools:

- `search_company_reports(symbol, query, document_types)`
- `get_latest_annual_report(symbol)`
- `get_latest_quarterly_report(symbol)`
- `get_company_citations(symbol, query)`
- `list_company_documents(symbol)`

Phase 4 implements equivalent HTTP APIs for document upload/list/detail and `/rag/search`. Runtime MCP tools are still deferred to the agent/chat phase.
