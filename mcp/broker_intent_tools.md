# Broker Intent Tools

Planned confirmation-required tools:

- `create_order_intent(user_id, portfolio_id, symbol, side, amount_or_quantity, order_type)`
- `preview_order_intent(order_intent_id)`
- `confirm_order_intent(order_intent_id)`
- `generate_whatsapp_broker_message(order_intent_id)`
- `cancel_order_intent(order_intent_id)`

No live trade execution is implemented in Phase 1.
